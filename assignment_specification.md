## Tasks

### Task 1 (18 marks)

Figure 1 shows two hosts A and B, in the same subnet. Host A sends a text message to a remote host C over a Secure Socket Layer (SSL). Simultaneously, host B is making a voice call to host D using a real-time communication protocol. C and D are in different networks with A and B.

1. **Multiplexing (5 marks):** Explain the technical details of multiplexing packets from A and B before the packets are sent from the gateway router. You are required to specify the detailed processing of different layers in the TCP/IP model.

2. **Router Processing (5 marks):** Describe how router R processes incoming packets, starting from packet reception to packets being sent out of the router.

3. **Delay Calculation (5 marks):** How the end-to-end delay of A-C and B-D communication is calculated.

4. **Time Comparison (2 marks):** If the transmission of one packet takes 0.02 ms, while the propagation time between A and C is 6 ms, can you conclude that the transmission time is less than propagation time in general? Give the rationale.

5. **Clear Presentation (1 mark):** The answers should be easy to understand and follow in a good presentation style.

> **Note:** The answer to each of the above questions must include one of the following: a technical diagram, a table, or application (e.g., Wireshark) screenshots to illustrate the technical details supporting your discussion.

### Task 2 (17 marks)

Recall Lab 6 CRC implementation with socket programming. Instead of writing the code yourself, you are now required to rewrite the Python code of CRC implementation using tools like ChatGPT. Write a technical essay using the template provided to demonstrate:

1. In what situation the CRC implementation is provided with socket programming? (4 marks)

2. How you interacted with ChatGPT to obtain the required code? (5 marks)

3. How you tested the code generated by ChatGPT to ensure it functions correctly. (6 marks)

4. **Formatting and referencing (2 marks).**

> **Note:** The maximum page limit for Task 2 is 4 pages, excluding references. You may include additional supporting details in the Appendix, which is not counted toward the page limit. However, all key information and main discussions must be presented within the 4-page limit. In other words, the report should be fully assessable without requiring the marker to read the Appendix. Please do not modify the font size or formatting provided in the template. Failure to comply with the formatting requirements will result in a 30% deduction in marks.

While your report should address all questions listed in Task 2, we also expect to see insightful analysis, critical discussion, and meaningful findings throughout your essay.
